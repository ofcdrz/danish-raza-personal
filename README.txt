ISARA WEBSITE - GITHUB PAGES SETUP

FILES
- index.html: main website
- ethnic-wear.html: separate Ethnic Wear page
- party-wear.html: separate Party Wear page
- assets/: supplied clothing photos

UPLOAD
1. Open your GitHub repository: ofcdrz/danish-raza-personal
2. Click Add file > Upload files.
3. Extract this ZIP on your computer.
4. Upload index.html, ethnic-wear.html, party-wear.html and the complete assets folder.
   Important: keep the assets folder and its photos together.
5. Commit changes directly to main.
6. Wait 2-5 minutes and refresh https://ofcdrz.github.io/danish-raza-personal/

PHOTO ADJUSTMENT
- On the home page, click ADJUST PHOTO under the About image or gallery photos.
- On Ethnic Wear and Party Wear pages, click ADJUST PHOTO below any photo.
- Use zoom, horizontal position, vertical position, frame height and image fit.
- These controls preview changes in your browser. Copy CSS SETTINGS to keep a record.
- To make an adjustment permanent for all visitors, the HTML/CSS needs to be updated and committed to GitHub.

ADDING MORE PHOTOS
1. Upload new image files into the assets folder in GitHub.
2. Open ethnic-wear.html or party-wear.html.
3. Copy an existing gallery item block and change its image path and alt text.
4. Commit changes.
